RA ceiling explorer

One categorical field, scored the way the ProxyDrift paper (arXiv 2608.08245, Sec. 4) scores it: JS distance to production, rescaled so 1 = identical and 0 = a random shuffle of the eval set's own value shares. Production is a known Zipf-shaped field. The eval set is n records drawn from it, with a share lambda of them drawn from a drifted version (same values, order reversed). Independent simulation; not affiliated with the paper's authors or Microsoft.

Aggregates only mode

For when production records cannot be sampled. Paste one field's production value shares (or counts) as aggregated, and the eval-set size n. The page returns the score a perfect n-record sample would get and its spread, from a closed formula and from simulated draws of those shares. Add the eval set's own counts to get its RA field score, the noise-adjusted score and how far it sits below the ceiling. Everything runs in your browser; nothing is sent anywhere.

Closed formula: E[d] = m(K-1) / sqrt(8 n ln 2), with m(k) = E[sqrt of a chi-square with k degrees of freedom], over a shuffle baseline b(n) = sqrt(B^2 + (K-1)/(8 n ln 2)), where B is the mean JS distance between the shares and a shuffle of themselves. K counts values with a nonzero share. It is rough for near-flat fields at small n (use the simulated number there). Noise-adjusted score = min(1, RA / ceiling). Gap = (ceiling - RA) / ceiling sd; above 1.645 means the eval set is below where 95% of perfect samples land. One field only: a total over many fields also needs the field weights, and its spread needs pairwise co-occurrence tables (see the repo README).
